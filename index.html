Antes de empezar

Para trabajar en clase y en casa necesitás:

  • Visual Studio Code con la extensión Live Server.
  • Google Chrome, Edge o Firefox actualizado. Vamos a usar mucho las herramientas para desarrolladores (F12).
  • Una carpeta por ejercicio o proyecto, con index.html, style.css y script.js.

Cómo usar este material

Cada unidad arranca con lo que vas a aprender, explica los temas con ejemplos que podés copiar (pasá el mouse sobre el código y vas a ver el botón Copiar) y termina con ejercicios. El último de cada unidad, marcado en amarillo, integra todo lo visto.

A lo largo del texto vas a encontrar estos recuadros:

Consejos prácticos y atajos que te ahorran tiempo.

Curiosidades y contexto. No es necesario memorizarlos.

Temas que no vemos en clase y quedan para que investigues por tu cuenta. La mejor fuente es la documentación de MDN.

Recursos recomendados

  • MDN Web Docs: la referencia oficial de todo lo que es web. Si dudás de cómo funciona algo, buscalo ahí.
  • javascript.info: un tutorial muy completo, en castellano, para profundizar cualquier tema.
  • Documentación de Chrome DevTools: todo lo que se puede hacer con la consola y el depurador.
