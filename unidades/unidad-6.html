DOM y eventos

Dejamos atrás prompt y alert: desde ahora JavaScript lee y modifica la página, y reacciona a lo que hace el usuario.

Al terminar esta unidad vas a poder

  • Explicar qué es el DOM y seleccionar elementos con querySelector.
  • Cambiar textos, atributos, clases y estilos desde JavaScript.
  • Crear y eliminar elementos, y dibujar una lista a partir de un array.
  • Responder a clics, teclas y escritura con addEventListener.
  • Usar delegación de eventos y atributos data-*.

¿Qué es el DOM?

Cuando el navegador lee tu HTML, arma en memoria un árbol de objetos: cada etiqueta se convierte en un objeto (un nodo) con propiedades y métodos. Ese árbol se llama DOM (Document Object Model), y JavaScript lo puede leer y modificar. Cada cambio en el DOM se ve al instante en la pantalla.

Este HTML…

<body>
  <h1>Mi lista</h1>
  <ul id="lista">
    <li>Pan</li>
    <li class="urgente">Leche</li>
  </ul>
  <button>Agregar</button>
</body>

…se convierte en este árbol:

En DevTools, la pestaña Elements muestra el DOM en vivo. Si JavaScript agrega o cambia algo, lo vas a ver ahí (y no en el código fuente del HTML).

Seleccionar elementos

Para modificar un elemento primero hay que “agarrarlo”. La forma moderna es con selectores de CSS, los mismos que ya conocés: 

// El PRIMER elemento que coincide con el selector (o null si no hay ninguno)
const titulo = document.querySelector("h1");
const lista = document.querySelector("#lista");
const urgente = document.querySelector(".urgente");
const primerItem = document.querySelector("#lista li");

// TODOS los que coinciden (una NodeList, parecida a un array)
const items = document.querySelectorAll("li");
console.log(items.length); // 2

items.forEach((item) => console.log(item.textContent));

También existe document.getElementById("lista") (sin el #), que vas a ver mucho en código existente.

Si ves TypeError: Cannot read properties of null, el querySelector no encontró nada. Revisá: ¿está bien escrito el selector? ¿Te olvidaste el # o el .? ¿El <script> tiene defer?

Leer y modificar contenido

const titulo = document.querySelector("h1");

// Leer y cambiar el texto
console.log(titulo.textContent); // "Mi lista"
titulo.textContent = "Lista del súper";

// Atributos: muchos se usan directamente como propiedades
const foto = document.querySelector("img");
foto.src = "img/gato.jpg";
foto.alt = "Un gato durmiendo";

const enlace = document.querySelector("a");
enlace.href = "https://developer.mozilla.org";

// Ocultar y mostrar
titulo.hidden = true;
titulo.hidden = false;

textContent vs innerHTML

const caja = document.querySelector(".caja");

caja.textContent = "<strong>Hola</strong>"; // muestra literalmente: <strong>Hola</strong>
caja.innerHTML = "<strong>Hola</strong>";   // muestra: Hola (en negrita)

Nunca uses innerHTML con texto que escribió el usuario o que vino de internet. Si alguien escribe <img src=x onerror="...">, el navegador ejecuta ese código. Para mostrar texto, usá siempre textContent.

Clases y estilos

La mejor forma de cambiar el aspecto de un elemento es agregar o quitar clases y dejar que el CSS haga el resto:

style.css

.oculto {
  display: none;
}
.activo {
  background: gold;
  font-weight: bold;
}

script.js

const boton = document.querySelector("button");

boton.classList.add("activo");       // agrega la clase
boton.classList.remove("activo");    // la quita
boton.classList.toggle("activo");    // si la tiene la quita, si no la agrega
boton.classList.contains("activo");  // true o false

También podés cambiar estilos directamente con style. Las propiedades se escriben en camelCase (background-color → backgroundColor): 

boton.style.backgroundColor = "tomato";
boton.style.fontSize = "20px";

Usá style solo para valores que se calculan en el momento (una posición, un color al azar). Para todo lo demás, clases: el diseño queda en el CSS y es más fácil de cambiar.

Crear y eliminar elementos

const lista = document.querySelector("#lista");

// 1. Crear el elemento (todavía no está en la página)
const item = document.createElement("li");

// 2. Configurarlo
item.textContent = "Manteca";
item.classList.add("nuevo");

// 3. Insertarlo
lista.append(item);   // al final de la lista
// lista.prepend(item); // o al principio

// Eliminar un elemento
item.remove();

Dibujar una lista a partir de un array

Este es el patrón más importante de la unidad: los datos viven en un array y una función los “dibuja” en la página. Cada vez que los datos cambian, se vuelve a llamar a la función. 

const compras = ["Pan", "Leche", "Yerba"];
const lista = document.querySelector("#lista");

function mostrarCompras() {
  lista.innerHTML = ""; // vaciamos lo que había

  compras.forEach((producto) => {
    const li = document.createElement("li");
    li.textContent = producto;
    lista.append(li);
  });
}

mostrarCompras();

// Más tarde, cuando cambian los datos:
compras.push("Café");
mostrarCompras();

Usamos innerHTML = "" solo para vaciar el contenedor: no hay riesgo porque no insertamos texto de nadie.

Eventos

Un evento es algo que pasa en la página: un clic, una tecla, el usuario escribiendo. Con addEventListener le decimos al navegador “cuando pase esto en este elemento, ejecutá esta función”. 

const boton = document.querySelector("#saludar");

boton.addEventListener("click", () => {
  console.log("¡Hiciste clic!");
});

¿Te suena? Es otra vez un callback: la función no se ejecuta ahora, sino cada vez que ocurra el clic.

Eventos más usados

EventoOcurre cuando…
clickse hace clic (o se toca en el celular)
inputcambia el contenido de un campo, con cada tecla
changese confirma un cambio en un campo, select o checkbox
keydownse aprieta una tecla
mouseenter / mouseleaveel mouse entra o sale de un elemento
submitse envía un formulario (Unidad 7)

El objeto evento

El callback recibe un parámetro (por convención e o evento) con información de lo que pasó: 

// e.target: el elemento donde ocurrió el evento
const campo = document.querySelector("#nombre");
const saludo = document.querySelector("#saludo");

campo.addEventListener("input", (e) => {
  saludo.textContent = `Hola, ${e.target.value}`; // se actualiza mientras escribís
});

// e.key: qué tecla se apretó
document.addEventListener("keydown", (e) => {
  if (e.key === "Escape") {
    console.log("Apretaste Escape");
  }
});

Ejemplo completo: un contador

index.html

<p id="valor">0</p>
<button id="restar">−</button>
<button id="sumar">+</button>
<button id="reiniciar">Reiniciar</button>

script.js

const valor = document.querySelector("#valor");
let contador = 0;

function actualizar() {
  valor.textContent = contador;
  valor.classList.toggle("negativo", contador < 0); // agrega la clase solo si es negativo
}

document.querySelector("#sumar").addEventListener("click", () => {
  contador++;
  actualizar();
});

document.querySelector("#restar").addEventListener("click", () => {
  contador--;
  actualizar();
});

document.querySelector("#reiniciar").addEventListener("click", () => {
  contador = 0;
  actualizar();
});

Vas a encontrar código con onclick="..." dentro del HTML. Funciona, pero mezcla estructura con comportamiento. En el curso usamos siempre addEventListener.

Delegación de eventos y data-*

Si una lista tiene 50 botones de “eliminar” creados dinámicamente, no hace falta ponerle un listener a cada uno. Le ponemos uno solo al contenedor y preguntamos dónde se hizo clic. Esto funciona porque los eventos “suben” desde el elemento clickeado hacia sus padres.

Para saber qué elemento eliminar, guardamos un dato en el HTML con un atributo data-* y lo leemos con dataset: 

let compras = ["Pan", "Leche", "Yerba"];
const lista = document.querySelector("#lista");

function mostrarCompras() {
  lista.innerHTML = "";
  compras.forEach((producto, indice) => {
    const li = document.createElement("li");
    li.textContent = producto;

    const boton = document.createElement("button");
    boton.textContent = "✕";
    boton.dataset.indice = indice; // genera <button data-indice="0">

    li.append(boton);
    lista.append(li);
  });
}

// UN solo listener para toda la lista
lista.addEventListener("click", (e) => {
  const boton = e.target.closest("button"); // ¿se hizo clic en un botón (o dentro de uno)?
  if (!boton) return;                       // clic en otro lado: no hacemos nada

  const indice = Number(boton.dataset.indice);
  // filter también recibe el índice; "_" es el elemento, que acá no usamos
  compras = compras.filter((_, i) => i !== indice);
  mostrarCompras();
});

mostrarCompras();

dataset traduce los nombres: data-id → dataset.id, data-precio-final → dataset.precioFinal. Los valores siempre son strings.

  • Qué son las fases de captura y burbujeo (bubbling), y para qué sirve e.stopPropagation().
  • removeEventListener: cómo dejar de escuchar un evento.
  • La etiqueta <template> para crear elementos complejos sin tantas líneas de createElement.
  • Recorrer el árbol: parentElement, children, nextElementSibling.

Práctica

1 · Contador con límites

Partiendo del contador de ejemplo: que no pueda bajar de 0 ni pasar de 10, que el botón correspondiente se deshabilite al llegar al límite (boton.disabled = true) y que el número se ponga rojo al llegar a 10.

2 · Modo oscuro

Un botón que alterna la clase oscuro en el <body>. En el CSS, definí los colores con variables y cambiá sus valores dentro de body.oscuro. El texto del botón tiene que cambiar entre “🌙 Oscuro” y “☀️ Claro”.

Pista para el CSS 
:root { --fondo: #fff; --texto: #222; }
body.oscuro { --fondo: #1e1e1e; --texto: #eee; }
body { background: var(--fondo); color: var(--texto); }

3 · Preguntas frecuentes

Armá en HTML una lista de 4 preguntas con sus respuestas ocultas. Al hacer clic en una pregunta se muestra su respuesta, y si había otra abierta, se cierra.

4 · Buscador en vivo

Dado un array de 15 nombres de países, mostralos en una lista. Agregá un <input> que, mientras escribís, filtre la lista para mostrar solo los que contienen ese texto (sin importar mayúsculas). Si no hay resultados, mostrá “Sin coincidencias”.

5 · Catálogo de productos (integrador)

Usando el array de productos de la Unidad 5 (agregale un id a cada uno):

  • Mostrá cada producto como una tarjeta con nombre, precio formateado y un botón “Agregar”.
  • Arriba, botones para filtrar por categoría (“Todos”, “Periféricos”, “Audio”, “Pantallas”). El filtro activo se tiene que notar.
  • Los productos sin stock se muestran grises y con el botón deshabilitado.
  • Un contador en el encabezado: “🛒 3 productos — $67.000”.
Pista

Escribí una función mostrarProductos(lista) que dibuje cualquier array de productos. Los botones de categoría solo llaman a esa función con el array filtrado. Para los botones “Agregar”, usá delegación con data-id.
