Arrays, objetos y strings

Hasta ahora cada variable guardaba un solo dato. Ahora vamos a guardar listas (arrays) y fichas con varios datos (objetos), y a trabajar con texto en serio.

Al terminar esta unidad vas a poder

  • Crear arrays, acceder a sus elementos, agregar y quitar.
  • Recorrer un array con for y for...of.
  • Representar datos con objetos y combinarlos en arrays de objetos.
  • Usar los métodos de string más comunes.

Arrays

Un array es una lista ordenada de valores guardada en una sola variable. Se escribe entre corchetes y los elementos se separan con comas. 

const frutas = ["manzana", "banana", "naranja"];
const notas = [8, 6, 10, 7];
const vacio = [];

Acceder por índice

Cada elemento tiene una posición llamada índice, que empieza en 0. 

const frutas = ["manzana", "banana", "naranja"];
//                 0         1          2

console.log(frutas[0]);      // "manzana"
console.log(frutas[2]);      // "naranja"
console.log(frutas[5]);      // undefined (no existe)
console.log(frutas.length);  // 3

// El último elemento siempre está en length - 1
console.log(frutas[frutas.length - 1]); // "naranja"

// Cambiar un elemento
frutas[1] = "pera";
console.log(frutas); // ["manzana", "pera", "naranja"]

Agregar y quitar

const fila = ["Ana", "Luis"];

fila.push("Sofía");          // ["Ana", "Luis", "Sofía"]
const atendido = fila.shift(); // atendido = "Ana", fila = ["Luis", "Sofía"]

Buscar y unir

const colores = ["rojo", "verde", "azul"];

colores.includes("verde");  // true
colores.indexOf("azul");    // 2
colores.indexOf("negro");   // -1 → no está
colores.join(", ");         // "rojo, verde, azul"

Recorrer un array

Con un for clásico, usando el índice:

const notas = [8, 6, 10, 7];

for (let i = 0; i < notas.length; i++) {
  console.log(`Nota ${i + 1}: ${notas[i]}`);
}

Si no necesitás el índice, for...of es más simple: en cada vuelta te da directamente el elemento. 

let suma = 0;

for (const nota of notas) {
  suma += nota;
}

console.log(`Promedio: ${suma / notas.length}`); // Promedio: 7.75

Fijate que la condición es i < notas.length y no <=. Si el array tiene 4 elementos, los índices van de 0 a 3. Usar <= te da una vuelta de más con undefined.

const no significa “no se puede modificar”

Un array declarado con const sí se puede modificar (agregar, quitar, cambiar elementos). Lo que no se puede es reasignar la variable a otro array. 

const lista = [1, 2, 3];

lista.push(4);    // ✅ modificar el contenido está permitido
lista[0] = 100;   // ✅

lista = [5, 6];   // ❌ TypeError: Assignment to constant variable.

Lo mismo pasa con los objetos. Por eso casi siempre se declaran con const.

const copia = lista; no copia el array: las dos variables apuntan al mismo array, y si modificás una, “se modifica la otra”. Para hacer una copia real se usa [...lista] (ver el recuadro de abajo).

Objetos

Un objeto agrupa datos relacionados en pares propiedad: valor. Mientras un array es una lista, un objeto es como una ficha. 

const alumno = {
  nombre: "Lucía",
  edad: 19,
  ciudad: "Rafaela",
  activo: true,
  materias: ["HTML", "CSS", "JavaScript"],
};

Leer y modificar propiedades

// Notación de punto (la más común)
console.log(alumno.nombre);        // "Lucía"
console.log(alumno.materias[2]);   // "JavaScript"

// Notación de corchetes: útil cuando el nombre está en una variable
const campo = "ciudad";
console.log(alumno[campo]);        // "Rafaela"

// Modificar y agregar
alumno.edad = 20;
alumno.email = "lucia@mail.com";   // si no existía, se crea

// Eliminar
delete alumno.activo;

// Una propiedad inexistente da undefined, no error
console.log(alumno.telefono);      // undefined

Para ver un objeto o un array de objetos de forma prolija en la consola usá console.table(alumno).

¿Array u objeto?

Usá un array cuando…Usá un objeto cuando…
tenés muchos elementos del mismo tipo: una lista de nombres, de precios, de tareas. tenés varios datos de una misma cosa: el nombre, precio y stock de un producto.
importa el orden y accedés por posición. accedés a cada dato por su nombre.

Arrays de objetos

La combinación más usada en la vida real: una lista de fichas. Productos de una tienda, alumnos de un curso, resultados de una búsqueda. Cuando en la Unidad 8 traigamos datos de internet, van a llegar con esta forma. 

const productos = [
  { id: 1, nombre: "Teclado", precio: 25000, stock: 4 },
  { id: 2, nombre: "Mouse", precio: 12000, stock: 0 },
  { id: 3, nombre: "Monitor", precio: 180000, stock: 2 },
];

console.log(productos[1].nombre); // "Mouse"

// Recorrer y mostrar los que tienen stock
for (const producto of productos) {
  if (producto.stock > 0) {
    console.log(`${producto.nombre}: $${producto.precio}`);
  }
}

// Calcular el valor total del inventario
let total = 0;
for (const producto of productos) {
  total += producto.precio * producto.stock;
}
console.log(`Inventario: $${total}`); // Inventario: $460000
  • El operador spread ...: cómo copiar o combinar arrays y objetos.
  • Desestructuración: const { nombre, precio } = producto;
  • Object.keys(), Object.values() y el bucle for...in para recorrer las propiedades de un objeto.
  • splice() y slice() en arrays: nombres parecidos, comportamientos muy distintos.

Métodos de strings

Un string se comporta parecido a un array de letras: tiene length y se puede acceder a cada carácter por índice. Además trae muchos métodos útiles. 

const texto = "  JavaScript es genial  ";

texto.length;               // 24 (los espacios cuentan)
texto.trim();               // "JavaScript es genial" → saca espacios de los extremos
texto.trim().toUpperCase(); // "JAVASCRIPT ES GENIAL"
texto.toLowerCase();        // "  javascript es genial  "

Buscar

const frase = "Aprender JavaScript es divertido";

frase.includes("Script");      // true (distingue mayúsculas)
frase.startsWith("Aprender");  // true
frase.endsWith(".");           // false
frase.indexOf("Java");         // 9
frase[0];                      // "A"

Extraer y reemplazar

const fecha = "2026-10-07";

fecha.slice(0, 4);   // "2026"  (desde el índice 0 hasta el 4, sin incluirlo)
fecha.slice(5, 7);   // "10"
fecha.slice(-2);     // "07"    (índices negativos cuentan desde el final)

"Hola mundo".replace("mundo", "clase");  // "Hola clase"
"a-b-c".replaceAll("-", "/");            // "a/b/c"
"ja".repeat(3);                          // "jajaja"
"7".padStart(3, "0");                    // "007"

Pasar de string a array y viceversa

split() corta un string en un array usando un separador, y join() hace lo contrario. Es la forma de procesar listas que escribe el usuario: 

const entrada = "Ana, Luis ,  Sofía";
const nombres = entrada.split(",");
console.log(nombres); // ["Ana", " Luis ", "  Sofía"] ← quedaron espacios

// Limpiamos cada nombre
for (let i = 0; i < nombres.length; i++) {
  nombres[i] = nombres[i].trim();
}
console.log(nombres);           // ["Ana", "Luis", "Sofía"]
console.log(nombres.join(" | ")); // "Ana | Luis | Sofía"

// Dar vuelta una palabra
"hola".split("").reverse().join(""); // "aloh"

Los strings son inmutables: ningún método cambia el string original, siempre devuelven uno nuevo. Si querés conservar el resultado, guardalo: nombre = nombre.trim();

Para comparar lo que escribe el usuario sin que importen mayúsculas ni espacios, normalizá primero: respuesta.trim().toLowerCase() === "si".

Dado el array const notas = [7, 4, 9, 10, 6, 3, 8];, calculá con bucles: el promedio, la nota más alta, la más baja y cuántos aprobaron (nota ≥ 6).

3 · Palíndromos

Escribí una función esPalindromo(texto) que devuelva si un texto se lee igual al derecho y al revés, ignorando mayúsculas y espacios. "Anita lava la tina" → true.
