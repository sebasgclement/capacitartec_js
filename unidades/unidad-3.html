Bucles y funciones

Repetir tareas sin copiar y pegar código, y organizar el programa en piezas reutilizables con nombre propio.

Al terminar esta unidad vas a poder

  • Repetir código con while y for, usando contadores y acumuladores.
  • Declarar funciones con parámetros, valores por defecto y return.
  • Escribir funciones flecha y pasar funciones como argumento.
  • Entender el alcance (scope) de las variables.
  • Leer mensajes de error y pausar el código con breakpoints.

El bucle while

while (“mientras”) repite un bloque mientras la condición sea verdadera. Antes de cada vuelta vuelve a revisar la condición. 

let contador = 1;

while (contador <= 3) {
  console.log(`Vuelta ${contador}`);
  contador++; // sin esta línea, el bucle no termina nunca
}

console.log("Fin");
Vuelta 1 Vuelta 2 Vuelta 3 Fin

Es ideal cuando no sabés de antemano cuántas vueltas vas a dar. Por ejemplo, insistir hasta que el usuario escriba un número válido: 

let edad = Number(prompt("¿Cuántos años tenés?"));

while (Number.isNaN(edad) || edad <= 0) {
  edad = Number(prompt("Eso no es válido. ¿Cuántos años tenés?"));
}

alert(`Perfecto, tenés ${edad} años`);

Si la condición nunca se vuelve falsa, tenés un bucle infinito y la pestaña se congela. Cerrala y revisá que algo dentro del bucle haga cambiar la condición.

El bucle for

Cuando sabés cuántas veces repetir, for junta en una sola línea las tres partes de un contador: 

//   inicio      condición   actualización
for (let i = 1; i <= 5;     i++) {
  console.log(i);
}
// 1 2 3 4 5
  1. Inicio: se ejecuta una sola vez, antes de empezar.
  2. Condición: se revisa antes de cada vuelta. Si es falsa, el bucle termina.
  3. Actualización: se ejecuta al final de cada vuelta.

Por convención, el contador se llama i. Algunos ejemplos: 

// Cuenta regresiva
for (let i = 10; i >= 1; i--) {
  console.log(i);
}

// Solo los pares hasta 20
for (let i = 0; i <= 20; i += 2) {
  console.log(i);
}

// Tabla del 7
for (let i = 1; i <= 10; i++) {
  console.log(`7 × ${i} = ${7 * i}`);
}

Acumuladores

Un patrón que vas a usar siempre: una variable que arranca en 0 y en cada vuelta suma algo. 

let suma = 0;

for (let i = 1; i <= 100; i++) {
  suma += i;
}

console.log(suma); // 5050

break y continue

  • break corta el bucle por completo.
  • continue saltea lo que queda de esta vuelta y pasa a la siguiente.
// Sumar números hasta que el usuario escriba 0
let total = 0;

while (true) {
  const numero = Number(prompt("Ingresá un número (0 para terminar)"));

  if (numero === 0) break;          // salimos del bucle
  if (Number.isNaN(numero)) continue; // ignoramos lo inválido y volvemos a pedir

  total += numero;
}

alert(`Total: ${total}`);

Funciones

Una función es un bloque de código con nombre que podés ejecutar todas las veces que quieras. Sirve para no repetir código y para dividir un problema grande en partes chicas. 

// 1. Declarar la función (todavía no se ejecuta nada)
function saludar() {
  console.log("¡Hola!");
}

// 2. Llamarla (ahora sí se ejecuta)
saludar();
saludar();

Parámetros y argumentos

Los parámetros son variables que la función recibe. Los valores que le pasás al llamarla se llaman argumentos. 

function saludar(nombre) {      // nombre es un parámetro
  console.log(`¡Hola, ${nombre}!`);
}

saludar("Ana");   // "Ana" es el argumento → ¡Hola, Ana!
saludar("Lucas"); // ¡Hola, Lucas!

Devolver un valor con return

return devuelve un resultado a quien llamó la función, para que lo pueda guardar o usar. Además, termina la función en ese momento. 

function calcularIva(precio) {
  return precio * 0.21;
}

const iva = calcularIva(1000);
console.log(iva);                     // 210
console.log(calcularIva(500) + 100);  // 205

console.log muestra un valor; return lo devuelve. Son cosas distintas. Una función sin return devuelve undefined, y es un error muy común: 

function sumar(a, b) {
  console.log(a + b); // lo muestra, pero no lo devuelve
}
const resultado = sumar(2, 3);
console.log(resultado * 2); // NaN, porque resultado es undefined

Valores por defecto

function calcularPrecioFinal(precio, iva = 21) {
  return precio + (precio * iva) / 100;
}

calcularPrecioFinal(1000);     // 1210 (usa iva = 21)
calcularPrecioFinal(1000, 10.5); // 1105

Funciones que deciden

Una función que devuelve true/false hace que los if se lean casi como una frase: 

function esPar(numero) {
  return numero % 2 === 0;
}

if (esPar(10)) {
  console.log("Es par");
}

Expresiones de función y funciones flecha

Una función también se puede guardar en una variable. Estas tres son equivalentes:

// Declaración
function doble(n) {
  return n * 2;
}

// Expresión de función
const doble2 = function (n) {
  return n * 2;
};

// Función flecha (arrow function)
const doble3 = (n) => {
  return n * 2;
};

Las funciones flecha tienen un atajo: si el cuerpo es una sola expresión, podés sacar las llaves y el return, que queda implícito. 

const doble = (n) => n * 2;
const sumar = (a, b) => a + b;
const saludar = () => console.log("Hola"); // sin parámetros: paréntesis vacíos

console.log(doble(4));    // 8
console.log(sumar(2, 3)); // 5

Para funciones “importantes” del programa podés usar la declaración clásica con function. Las flechas brillan en funciones cortas que se pasan como argumento, que es lo que vamos a hacer muchísimo desde la Unidad 5.

Alcance de las variables (scope)

Una variable declarada con let o const solo existe dentro del bloque { } donde se creó. 

function calcular() {
  const resultado = 42; // variable local de la función
  console.log(resultado); // ✅ 42
}

calcular();
console.log(resultado); // ❌ ReferenceError: resultado is not defined

if (true) {
  let mensaje = "hola";
}
console.log(mensaje); // ❌ tampoco existe fuera del if

Las variables declaradas fuera de todo bloque son globales y se pueden usar en cualquier parte. Parece cómodo, pero conviene evitarlas: cualquier función podría cambiarlas sin que te des cuenta.

Una buena función recibe todo lo que necesita por parámetros y entrega su resultado con return, sin tocar variables de afuera.

Las funciones son valores

Así como pasás un número o un texto a una función, también le podés pasar otra función. A la función que pasás se la llama callback. 

function saludar() {
  console.log("¡Hola!");
}

// setTimeout ejecuta la función que le pasamos después de 2000 ms
setTimeout(saludar, 2000);

// También podemos escribir la función ahí mismo
setTimeout(() => console.log("Pasaron 3 segundos"), 3000);

Fijate que escribimos saludar sin paréntesis. Con paréntesis, saludar() la ejecutaría en ese mismo momento y le pasaría a setTimeout el resultado (undefined), no la función.

Esta idea va a aparecer en todo el resto del curso: en los métodos de arrays (Unidad 5) y en los eventos de la página (Unidad 6).

  • ¿Por qué podés llamar a una función declarada con function antes de la línea donde la escribiste, pero no a una función flecha? (Buscá hoisting).
  • Qué es una función recursiva. Intentá escribir el factorial de un número de esa forma.

Depurar: encontrar y corregir errores

Tu código va a fallar. Muchas veces. Es parte del trabajo, y saber leer los errores es la habilidad que más tiempo te va a ahorrar.

Los tres errores más comunes

ErrorQué significaCausa típica
SyntaxError El código está mal escrito y ni siquiera se puede ejecutar. Falta cerrar una llave, un paréntesis o una comilla.
ReferenceError: x is not defined Usaste una variable que no existe (en ese lugar). Error de tipeo (nombre vs nombr), o la variable está en otro scope.
TypeError: x is not a function Intentaste hacer algo que ese tipo de dato no permite. Llamar con () algo que no es una función, o usar una propiedad de undefined.

Breakpoints: pausar el código

Cuando no hay error pero el resultado es incorrecto, conviene ver el código ejecutarse paso a paso:

  1. Abrí las DevTools y andá a la pestaña Sources (Fuentes).
  2. Abrí tu script.js y hacé clic en el número de una línea: aparece un marcador azul (el breakpoint).
  3. Recargá la página. La ejecución se detiene en esa línea.
  4. Pasá el mouse sobre las variables para ver su valor, o miralas en el panel Scope.
  5. Avanzá línea por línea con F10 (step over) y seguí normalmente con F8.

También podés escribir la palabra debugger en el código: con las DevTools abiertas, el programa se pausa ahí.

let suma = 0;
for (let i = 1; i <= 5; i++) {
  debugger; // pausa en cada vuelta: mirá cómo cambian i y suma
  suma += i;
}

Antes de pedir ayuda, hacete tres preguntas: ¿qué error dice la consola? ¿en qué línea? ¿qué valor tiene cada variable justo antes de esa línea? La mitad de las veces la respuesta aparece sola.

Práctica

1 · Tabla de multiplicar

Pedí un número y mostrá su tabla del 1 al 10 en la consola.

2 · Promedio de notas

Pedí notas una por una hasta que el usuario escriba 0. Al final mostrá cuántas notas ingresó, el promedio y la nota más alta.

3 · Funciones de utilidad

Escribí estas funciones y probalas con varios valores:

  • esMayorDeEdad(edad) → devuelve true o false.
  • aplicarDescuento(precio, porcentaje = 10) → devuelve el precio con descuento.
  • contarVocales(texto) → devuelve cuántas vocales tiene un texto.
Pista para contarVocales

Podés recorrer un string con un for, igual que un número: texto[i] es la letra en la posición i y texto.length es la cantidad de letras. Para saber si es vocal: "aeiou".includes(letra).

4 · Adiviná el número

El programa elige un número secreto del 1 al 100. El usuario tiene 7 intentos para adivinarlo y en cada uno le decís “más alto” o “más bajo”.

Pista

Para generar el número secreto usá esta línea (la explicamos en la Unidad 5): const secreto = Math.floor(Math.random() * 100) + 1;

5 · Cajero automático (integrador)

Simulá un cajero con un saldo inicial de $10.000 y un menú que se repite hasta que el usuario elija salir:

1) Consultar saldo
2) Depositar
3) Extraer
4) Salir
  • Cada operación tiene que ser una función: depositar(saldo, monto) devuelve el saldo nuevo.
  • No se puede extraer más de lo que hay ni ingresar montos negativos o inválidos.
  • Al salir, mostrá cuántas operaciones se hicieron.
Pista

Combiná un while para repetir el menú con un switch para elegir la operación.
