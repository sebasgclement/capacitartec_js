Operadores y decisiones

Hacer cuentas, comparar valores y lograr que el programa tome caminos distintos según lo que pasa.

Al terminar esta unidad vas a poder

  • Usar operadores aritméticos, de asignación, de comparación y lógicos.
  • Explicar por qué se usa === y no ==.
  • Escribir decisiones con if, el operador ternario y switch.
  • Validar que un dato ingresado por el usuario sea un número.

Operadores aritméticos

OperadorOperaciónEjemploResultado
+suma7 + 29
-resta7 - 25
*multiplicación7 * 214
/división7 / 23.5
%resto de la división7 % 21
**potencia7 ** 249

Se respeta el orden matemático de siempre: primero **, después * / % y al final + -. Ante la duda, usá paréntesis: 

console.log(2 + 3 * 4);   // 14
console.log((2 + 3) * 4); // 20

const promedio = (8 + 6 + 10) / 3;
console.log(promedio);    // 8

El operador resto %

Parece raro, pero se usa muchísimo. El caso más típico es saber si un número es par: si el resto de dividirlo por 2 es 0, es par. 

console.log(10 % 2); // 0 → par
console.log(7 % 2);  // 1 → impar
console.log(10 % 3); // 1

Probá 0.1 + 0.2 en la consola: da 0.30000000000000004. No es un bug de JavaScript, sino de cómo las computadoras guardan los decimales (pasa en casi todos los lenguajes). Para mostrar resultados con dinero usá numero.toFixed(2), que lo vemos en la Unidad 5.

Operadores de asignación

Son atajos para actualizar el valor de una variable a partir del valor que ya tenía:

let puntos = 10;

puntos += 5;  // es lo mismo que: puntos = puntos + 5  → 15
puntos -= 3;  // puntos = puntos - 3                   → 12
puntos *= 2;  // puntos = puntos * 2                   → 24
puntos /= 4;  // puntos = puntos / 4                   → 6

puntos++;     // suma 1 → 7
puntos--;     // resta 1 → 6

+= también funciona con strings, para ir agregando texto: mensaje += " y algo más";

Operadores de comparación

Comparan dos valores y siempre devuelven un booleano: true o false.

OperadorSignificaEjemploResultado
===igual (valor y tipo)5 === 5true
!==distinto5 !== 3true
>mayor5 > 3true
<menor5 < 3false
>=mayor o igual5 >= 5true
<=menor o igual4 <= 3false

¿Por qué === y no ==?

== (doble igual) convierte los tipos antes de comparar, y eso produce resultados difíciles de predecir. === (triple igual) compara valor y tipo, sin conversiones. 

console.log(5 == "5");   // true  😬
console.log(5 === "5");  // false ✅ uno es number y el otro string

console.log(0 == "");    // true  😬
console.log(0 === "");   // false ✅

Usá siempre === y !==. Si necesitás comparar un número con un texto, convertí primero el texto con Number().

Operadores lógicos

Sirven para combinar varias condiciones:

OperadorNombreDevuelve true cuando…
&&Y (AND)las dos condiciones son verdaderas
||O (OR)al menos una condición es verdadera
!NO (NOT)la condición es falsa (invierte el valor)
 
const edad = 20;
const tieneEntrada = true;
const esFeriado = false;

console.log(edad >= 18 && tieneEntrada); // true: se cumplen las dos
console.log(esFeriado || edad > 65);     // false: no se cumple ninguna
console.log(!esFeriado);                 // true

// Un número entre 1 y 10 (inclusive)
const n = 7;
console.log(n >= 1 && n <= 10);          // true

En matemática se escribe 1 ≤ n ≤ 10, pero en JavaScript 1 <= n <= 10 no funciona como esperás. Hay que escribir las dos comparaciones unidas con &&.

Condicionales: if, else if, else

Un condicional ejecuta un bloque de código solo si se cumple una condición: 

const temperatura = 31;

if (temperatura > 30) {
  console.log("Hace calor 🥵");
}

Con else definimos qué hacer cuando la condición no se cumple, y con else if agregamos más casos:

const nota = Number(prompt("Ingresá tu nota (1 a 10)"));

if (nota >= 7) {
  alert("Promocionaste 🎉");
} else if (nota >= 4) {
  alert("Aprobaste, vas al final");
} else {
  alert("Recursás");
}

Las condiciones se evalúan de arriba hacia abajo y se ejecuta solo el primer bloque que cumpla. Si la nota es 8, entra en el primero y los demás se ignoran, aunque 8 >= 4 también sea verdadero.

Indentá (sangrá) siempre el código que está dentro de las llaves. JavaScript no lo necesita, pero vos sí para leerlo. En VS Code, Shift + Alt + F formatea el archivo entero.

Validar lo que ingresa el usuario

Si el usuario escribe “hola” donde esperábamos un número, Number() da NaN. Lo podemos detectar con Number.isNaN(): 

const edad = Number(prompt("¿Cuántos años tenés?"));

if (Number.isNaN(edad)) {
  alert("Eso no es un número 🤨");
} else if (edad >= 18) {
  alert("Podés pasar");
} else {
  alert(`Te faltan ${18 - edad} años`);
}

No se puede comparar edad === NaN: NaN es el único valor de JavaScript que no es igual a sí mismo. Siempre usá Number.isNaN().

Truthy y falsy

Dentro de un if podés poner cualquier valor, no solo booleanos. JavaScript lo convierte a true o false según esta regla: hay exactamente seis valores falsy (que cuentan como falso) y todo lo demás es truthy.

Valores falsy
false · 0 · "" (string vacío) · null · undefined · NaN

Es muy útil para chequear si el usuario escribió algo:

const nombre = prompt("¿Cómo te llamás?");

// Si apretó Cancelar (null) o no escribió nada (""), es falsy
if (nombre) {
  alert(`Hola, ${nombre}`);
} else {
  alert("No ingresaste tu nombre");
}

Operador ternario

Es una forma corta de escribir un if/else que elige entre dos valores:

// condición ? valorSiEsVerdadera : valorSiEsFalsa
const edad = 20;
const mensaje = edad >= 18 ? "Mayor de edad" : "Menor de edad";
console.log(mensaje); // "Mayor de edad"

const cantidad = 1;
console.log(`Tenés ${cantidad} ${cantidad === 1 ? "mensaje" : "mensajes"}`);

Usalo solo para casos simples de “esto o aquello”. Si tenés que anidar un ternario dentro de otro, volvé al if: se lee mucho mejor.

switch

Cuando comparás una misma variable contra muchos valores exactos, switch queda más ordenado que una cadena de else if: 

const opcion = prompt("Elegí: 1) Saldo  2) Depositar  3) Salir");

switch (opcion) {
  case "1":
    alert("Tu saldo es $5000");
    break;
  case "2":
    alert("Depósito realizado");
    break;
  case "3":
    alert("¡Hasta luego!");
    break;
  default:
    alert("Opción inválida");
}
  • switch compara con ===: por eso los casos son "1" (string), porque prompt devuelve texto.
  • break corta el switch. Si lo olvidás, sigue ejecutando el caso de abajo.
  • default se ejecuta si no coincide ningún caso (como el else).

Podés agrupar varios casos que hacen lo mismo:

const dia = "sábado";

switch (dia) {
  case "sábado":
  case "domingo":
    console.log("Fin de semana");
    break;
  default:
    console.log("Día de semana");
}

Práctica

1 · Par o impar

Pedí un número y mostrá si es par o impar. Si no es un número, avisalo.

2 · El mayor de tres

Pedí tres números y mostrá cuál es el mayor (sin usar Math.max).

Pista

El primero es el mayor si es mayor que el segundo y mayor que el tercero.

3 · Año bisiesto

Un año es bisiesto si es divisible por 4, excepto los divisibles por 100, salvo que también sean divisibles por 400. Pedí un año e indicá si es bisiesto. (2024 sí, 1900 no, 2000 sí).

4 · Calculadora con switch

Pedí dos números y una operación (+, -, *, /). Mostrá el resultado. Si la operación es una división por cero o un símbolo desconocido, mostrá un mensaje de error.

5 · Cotizador de envíos (integrador)

Un correo cobra los envíos así:

  • Hasta 1 kg: $3000. De 1 a 5 kg: $5500. Más de 5 kg: $5500 + $900 por cada kg extra.
  • Si el destino es "local" hay 20 % de descuento; si es "nacional", precio normal.
  • Los envíos de más de 30 kg no se aceptan.

Pedí el peso y el destino, validá los datos y mostrá el precio final.

Pista

Resolvelo en partes: primero validá, después calculá el precio base con if/else if, y recién al final aplicá el descuento.
