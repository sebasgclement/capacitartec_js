Asincronía y APIs

Traer datos reales de internet —clima, cotizaciones, personajes, libros— y mostrarlos en tu página.

Al terminar esta unidad vas a poder

  • Explicar qué es el código asíncrono y qué es una promesa.
  • Pedir datos a una API con fetch.
  • Usar async/await con try/catch.
  • Mostrar estados de carga y de error en la interfaz.

Código que no espera

Hasta ahora todo se ejecutaba línea por línea, en orden. Pero algunas tareas tardan: pedir datos a un servidor puede demorar un segundo o más. Si JavaScript se quedara esperando, la página entera se congelaría. En lugar de eso, deja la tarea en marcha y sigue con lo demás; cuando la tarea termina, ejecuta lo que le dijimos. 

console.log("1. Pido una pizza");

setTimeout(() => {
  console.log("3. Llegó la pizza 🍕");
}, 2000);

console.log("2. Mientras tanto, pongo la mesa");
1. Pido una pizza 2. Mientras tanto, pongo la mesa 3. Llegó la pizza 🍕

A esto se le llama asincronía: el resultado llega después, no en la línea donde lo pediste.

Promesas

Una promesa es un objeto que representa un resultado que todavía no está. Es como el ticket que te dan al pedir en un local de comidas: todavía no tenés la comida, pero tenés la promesa de que va a llegar (o de que te avisen si se acabó).

Una promesa puede estar en uno de tres estados:

EstadoSignificaSe maneja con
pending (pendiente)todavía no terminó—
fulfilled (cumplida)terminó bien y tiene un valor.then()
rejected (rechazada)falló y tiene un error.catch()

No vas a crear promesas a mano casi nunca. Lo que vas a hacer es usar las que te devuelven funciones como fetch.

Pedir datos con fetch

Una API web es una dirección (URL) que, en lugar de devolver una página para ver, devuelve datos en formato JSON para que los use un programa. Probá abrir esta en el navegador: https://pokeapi.co/api/v2/pokemon/pikachu.

Desde JavaScript la pedimos con fetch, que devuelve una promesa:

fetch("https://pokeapi.co/api/v2/pokemon/pikachu")
  .then((respuesta) => respuesta.json()) // 1. convertimos la respuesta de JSON a objeto
  .then((pokemon) => {
    console.log(pokemon.name);           // 2. usamos los datos
    console.log(pokemon.weight);
  })
  .catch((error) => {
    console.error("Algo falló:", error); // si no hay internet, por ejemplo
  });

Son dos pasos porque respuesta.json() también es asíncrono: primero llegan los encabezados de la respuesta y después el contenido.

En DevTools, la pestaña Network (Red) muestra cada pedido que hace tu página. Hacé clic en uno y mirá la pestaña Preview para explorar el JSON que llegó y encontrar las propiedades que necesitás.

async / await

Encadenar .then() se vuelve difícil de leer. async/await permite escribir lo mismo como si fuera código normal, línea por línea: 

async function mostrarPokemon() {
  try {
    const respuesta = await fetch("https://pokeapi.co/api/v2/pokemon/pikachu");
    const pokemon = await respuesta.json();
    console.log(pokemon.name);
  } catch (error) {
    console.error("Algo falló:", error);
  }
}

mostrarPokemon();
  • await “espera” a que la promesa se cumpla y te da su valor.
  • Solo se puede usar await dentro de una función marcada con async.
  • Los errores se manejan con el try/catch que vimos en la Unidad 7.

Chequear respuesta.ok

fetch solo falla (va al catch) si no hubo conexión. Si el servidor responde “no encontrado” (error 404), para fetch eso es una respuesta válida. Por eso hay que revisarlo: 

async function buscarPokemon(nombre) {
  const respuesta = await fetch(`https://pokeapi.co/api/v2/pokemon/${nombre}`);

  if (!respuesta.ok) {
    // respuesta.status tiene el código: 404 = no existe, 500 = error del servidor…
    throw new Error(`No se encontró "${nombre}" (error ${respuesta.status})`);
  }

  return respuesta.json();
}

Una función async siempre devuelve una promesa. Para usar lo que devuelve buscarPokemon(), también tenés que usar await (o .then): const p = await buscarPokemon("ditto");

Ejemplo completo: buscador de Pokémon

Una interfaz real tiene que contemplar tres estados: cargando, error y éxito. Mientras carga, conviene deshabilitar el botón para que no se hagan pedidos repetidos.

index.html

<form id="buscador">
  <label for="nombre">Nombre o número</label>
  <input id="nombre" required placeholder="pikachu" />
  <button type="submit">Buscar</button>
</form>

<div id="resultado"></div>

script.js

const form = document.querySelector("#buscador");
const input = document.querySelector("#nombre");
const boton = form.querySelector("button");
const resultado = document.querySelector("#resultado");

async function buscarPokemon(nombre) {
  const respuesta = await fetch(`https://pokeapi.co/api/v2/pokemon/${nombre}`);
  if (!respuesta.ok) {
    throw new Error(respuesta.status === 404 ? "No existe ese Pokémon 🤔" : "Error del servidor");
  }
  return respuesta.json();
}

function mostrarPokemon(pokemon) {
  resultado.innerHTML = "";

  const titulo = document.createElement("h2");
  titulo.textContent = `#${pokemon.id} ${pokemon.name}`;

  const imagen = document.createElement("img");
  imagen.src = pokemon.sprites.front_default;
  imagen.alt = pokemon.name;

  const tipos = document.createElement("p");
  tipos.textContent = "Tipo: " + pokemon.types.map((t) => t.type.name).join(", ");

  resultado.append(titulo, imagen, tipos);
}

form.addEventListener("submit", async (e) => {
  e.preventDefault();
  const nombre = input.value.trim().toLowerCase();

  resultado.textContent = "Cargando…";
  boton.disabled = true;

  try {
    const pokemon = await buscarPokemon(nombre);
    mostrarPokemon(pokemon);
  } catch (error) {
    resultado.textContent = error.message;
  } finally {
    boton.disabled = false; // se ejecuta siempre, haya salido bien o mal
  }
});

Si no hay internet, fetch falla con el mensaje “Failed to fetch”. En una app real convendría mostrar algo más amigable, como “Revisá tu conexión”.

APIs para practicar

Todas son gratuitas y no requieren registrarse ni usar una clave:

APIQué tieneURL de ejemplo
PokeAPIPokémon, tipos, habilidadeshttps://pokeapi.co/api/v2/pokemon/ditto
Rick and Mortypersonajes, con paginaciónhttps://rickandmortyapi.com/api/character
JSONPlaceholderusuarios, posts y tareas de pruebahttps://jsonplaceholder.typicode.com/users
Open Librarylibros: autores, año, tapashttps://openlibrary.org/search.json?q=borges
Open-Meteoclima actual y pronósticohttps://api.open-meteo.com/v1/forecast?latitude=-31.25&longitude=-61.49&current=temperature_2m
DolarAPIcotizaciones del dólar en Argentinahttps://dolarapi.com/v1/dolares

Muchas APIs limitan cuántos pedidos podés hacer por hora. La de GitHub, por ejemplo, permite solo 60 por hora sin clave, contando a todas las computadoras que comparten la misma conexión. En un aula se agota en minutos. No hagas pedidos dentro de un evento input (uno por tecla): usá un botón o el submit.

  • Qué es CORS y por qué a veces el navegador bloquea un pedido a otra página.
  • Promise.all(): hacer varios pedidos a la vez y esperar a todos.
  • Los métodos HTTP (GET, POST, PUT, DELETE) y cómo enviar datos con fetch.
  • Por qué nunca se debe poner una clave de API secreta en el código del navegador.

Práctica

1 · Directorio de usuarios

Traé los usuarios de JSONPlaceholder y mostralos como tarjetas con nombre, email y ciudad (usuario.address.city). Mientras carga, mostrá “Cargando…”.

2 · Cotización del dólar

Con DolarAPI, mostrá una tabla con el nombre de cada cotización, su precio de compra y de venta, formateados como moneda. Agregá un botón “Actualizar” y la hora de la última actualización.

3 · Galería de Rick and Morty

Mostrá los personajes de la primera página con su imagen, nombre y estado. Agregá botones “Anterior” y “Siguiente” usando las URLs que vienen en datos.info.prev y datos.info.next. Deshabilitá el botón cuando no haya página anterior o siguiente.

4 · ¿Qué tiempo hace?

Con Open-Meteo, mostrá la temperatura actual de tu ciudad. Buscá su latitud y longitud en un mapa. Bonus: un <select> con 3 ciudades para elegir.

5 · Pokédex con favoritos (integrador)

A partir del buscador de ejemplo:

  • Mostrá también altura, peso y la lista de habilidades.
  • Un botón “☆ Favorito” que guarde el Pokémon (solo nombre, id e imagen) en localStorage.
  • Una sección “Mis favoritos” que se vea al cargar la página. Al hacer clic en uno, se busca de nuevo.
  • No se puede agregar dos veces el mismo, y se puede quitar de favoritos.
Pista

La API da la altura en decímetros y el peso en hectogramos: dividí ambos por 10 para mostrarlos en metros y kilos.
