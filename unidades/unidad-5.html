Métodos de array, Math y Date

Las herramientas que trae JavaScript para transformar listas sin escribir bucles a mano, hacer cálculos y trabajar con fechas.

Al terminar esta unidad vas a poder

  • Usar forEach, map, filter, find, some, every y reduce.
  • Ordenar arrays de números, textos y objetos con sort.
  • Redondear, generar números al azar y formatear precios.
  • Crear fechas, leer sus partes y calcular diferencias.

La idea: métodos que reciben funciones

En la Unidad 3 vimos que una función se puede pasar como argumento (un callback). Los arrays tienen métodos que reciben un callback y lo ejecutan una vez por cada elemento. Así, en lugar de escribir el bucle vos, solo decís qué hacer con cada elemento.

Para todos los ejemplos vamos a usar estos datos:

const productos = [
  { nombre: "Teclado", precio: 25000, categoria: "perifericos", stock: 4 },
  { nombre: "Mouse", precio: 12000, categoria: "perifericos", stock: 0 },
  { nombre: "Monitor", precio: 180000, categoria: "pantallas", stock: 2 },
  { nombre: "Auriculares", precio: 30000, categoria: "audio", stock: 7 },
  { nombre: "Parlante", precio: 45000, categoria: "audio", stock: 1 },
];

forEach: hacer algo con cada elemento

productos.forEach((producto) => {
  console.log(`${producto.nombre}: $${producto.precio}`);
});

// El callback también puede recibir el índice como segundo parámetro
productos.forEach((producto, i) => {
  console.log(`${i + 1}. ${producto.nombre}`);
});

Es equivalente a un for...of. No devuelve nada: se usa para hacer algo (mostrar, guardar, crear elementos en la página).

map: transformar cada elemento

Devuelve un array nuevo, del mismo largo, con lo que retorne el callback para cada elemento. El array original no cambia. 

const nombres = productos.map((p) => p.nombre);
// ["Teclado", "Mouse", "Monitor", "Auriculares", "Parlante"]

const preciosConIva = productos.map((p) => p.precio * 1.21);
// [30250, 14520, 217800, 36300, 54450]

const numeros = [1, 2, 3];
const dobles = numeros.map((n) => n * 2); // [2, 4, 6]

Si usás llaves en la flecha, tenés que escribir return. Sin return, map te devuelve un array lleno de undefined: 

numeros.map((n) => { n * 2 });        // [undefined, undefined, undefined]
numeros.map((n) => { return n * 2 }); // [2, 4, 6] ✅

filter: quedarse con algunos

Devuelve un array nuevo solo con los elementos para los que el callback devuelve true. 

const conStock = productos.filter((p) => p.stock > 0);
// Teclado, Monitor, Auriculares, Parlante

const audio = productos.filter((p) => p.categoria === "audio");
// Auriculares, Parlante

const baratos = productos.filter((p) => p.precio < 30000);
// Teclado, Mouse

// Si ninguno cumple, devuelve un array vacío []
const carisimos = productos.filter((p) => p.precio > 1000000); // []

filter también es la forma más simple de eliminar un elemento: te quedás con todos los que no son ese. tareas = tareas.filter((t) => t.id !== idABorrar);

find y findIndex: buscar uno

const monitor = productos.find((p) => p.nombre === "Monitor");
// { nombre: "Monitor", precio: 180000, ... }

const tablet = productos.find((p) => p.nombre === "Tablet");
// undefined → no lo encontró

const posicion = productos.findIndex((p) => p.nombre === "Mouse");
// 1 (si no lo encuentra, -1)

A diferencia de filter, find devuelve el primer elemento que cumple (no un array), o undefined. Siempre chequeá que lo haya encontrado antes de usarlo: 

const buscado = productos.find((p) => p.nombre === "Tablet");

if (buscado) {
  console.log(buscado.precio);
} else {
  console.log("No existe ese producto");
}

some y every: preguntar

// ¿Hay ALGÚN producto sin stock?
productos.some((p) => p.stock === 0);   // true

// ¿TODOS cuestan más de $10.000?
productos.every((p) => p.precio > 10000); // true

reduce: reducir a un solo valor

Recorre el array acumulando un resultado. Es el patrón del acumulador de la Unidad 3, pero en una línea. El callback recibe el acumulado hasta ahora y el elemento actual; el segundo argumento de reduce es el valor inicial. 

const numeros = [10, 20, 30];

const suma = numeros.reduce((acumulado, n) => acumulado + n, 0);
// vuelta 1: 0 + 10 = 10
// vuelta 2: 10 + 20 = 30
// vuelta 3: 30 + 30 = 60
console.log(suma); // 60

// Valor total del inventario
const inventario = productos.reduce((total, p) => total + p.precio * p.stock, 0);
console.log(inventario); // 715000

Si reduce te resulta difícil de leer, no pasa nada: un for...of con acumulador hace exactamente lo mismo. Usá el que entiendas.

sort: ordenar

A diferencia de map y filter, sort modifica el array original. Si querés conservarlo, ordená una copia: [...array].sort(...).

Sin argumentos, sort ordena como texto, lo cual da resultados raros con números: 

[10, 1, 5, 100].sort();  // [1, 10, 100, 5] 😬 los compara como "1", "10", "100", "5"

Para ordenar bien, se le pasa una función que compara dos elementos a y b:

const numeros = [10, 1, 5, 100];

numeros.sort((a, b) => a - b); // [1, 5, 10, 100]   menor a mayor
numeros.sort((a, b) => b - a); // [100, 10, 5, 1]   mayor a menor

// Textos (respeta acentos y ñ)
const nombres = ["Óscar", "ana", "Bruno"];
nombres.sort((a, b) => a.localeCompare(b)); // ["ana", "Bruno", "Óscar"]

// Objetos por una propiedad
const porPrecio = [...productos].sort((a, b) => a.precio - b.precio);

¿Por qué a - b? Si el resultado es negativo, a va antes; si es positivo, va después; si es 0, quedan igual.

Encadenar métodos

Como filter y map devuelven arrays, podés encadenarlos. Leelo de arriba hacia abajo como una receta: 

const listado = productos
  .filter((p) => p.stock > 0)            // 1. solo los que tienen stock
  .sort((a, b) => a.precio - b.precio)   // 2. ordenados por precio
  .map((p) => `${p.nombre} ($${p.precio})`) // 3. convertidos a texto
  .join("\n");                           // 4. unidos en un solo string

console.log(listado);
Teclado ($25000) Auriculares ($30000) Parlante ($45000) Monitor ($180000)

El objeto Math

Agrupa funciones matemáticas listas para usar:

Math.round(4.5);   // 5   redondea al más cercano
Math.floor(4.9);   // 4   redondea hacia abajo
Math.ceil(4.1);    // 5   redondea hacia arriba
Math.trunc(-4.7);  // -4  corta los decimales

Math.max(3, 9, 2); // 9
Math.min(3, 9, 2); // 2
Math.abs(-7);      // 7
Math.sqrt(16);     // 4
Math.PI;           // 3.141592653589793

Números al azar

Math.random() devuelve un decimal entre 0 (incluido) y 1 (sin incluir). Para obtener un entero en un rango, se combina con Math.floor: 

// Entero entre min y max (ambos incluidos)
function enteroAlAzar(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

enteroAlAzar(1, 6);   // un dado
enteroAlAzar(1, 100); // 1 a 100

// Elegir un elemento al azar de un array
const premios = ["auto", "bici", "nada"];
const premio = premios[enteroAlAzar(0, premios.length - 1)];

Mostrar números prolijos

const precio = 1234.5678;

precio.toFixed(2);  // "1234.57" ← ojo: devuelve un string

precio.toLocaleString("es-AR");  // "1.234,568"

precio.toLocaleString("es-AR", { style: "currency", currency: "ARS" });
// "$ 1.234,57"

Hacé las cuentas con números y formateá solo al final, cuando lo vas a mostrar. Si formateás antes, vas a terminar sumando strings.

Fechas con Date

const ahora = new Date();         // fecha y hora actual

ahora.getFullYear();  // 2026
ahora.getMonth();     // 0 a 11 ← ¡enero es 0!
ahora.getDate();      // día del mes, 1 a 31
ahora.getDay();       // día de la semana, 0 (domingo) a 6 (sábado)
ahora.getHours();     // 0 a 23
ahora.getMinutes();   // 0 a 59

Los meses empiezan en 0: enero es 0 y diciembre es 11. Es una de las trampas más famosas de JavaScript. Para mostrar el número “humano”, sumá 1.

Crear una fecha determinada

// año, mes (0-11), día, hora, minutos
const navidad = new Date(2026, 11, 25);       // 25 de diciembre de 2026
const turno = new Date(2026, 9, 15, 14, 30);  // 15 de octubre, 14:30

Mostrar fechas en castellano

const fecha = new Date(2026, 9, 7);

fecha.toLocaleDateString("es-AR"); // "7/10/2026"

fecha.toLocaleDateString("es-AR", {
  weekday: "long",
  day: "numeric",
  month: "long",
}); // "miércoles, 7 de octubre"

Diferencia entre fechas

Si restás dos fechas, obtenés la diferencia en milisegundos. Para pasarla a días, dividís por la cantidad de milisegundos de un día: 

const MS_POR_DIA = 1000 * 60 * 60 * 24;

const hoy = new Date();
const finDeAnio = new Date(hoy.getFullYear(), 11, 31);

const faltan = Math.ceil((finDeAnio - hoy) / MS_POR_DIA);
console.log(`Faltan ${faltan} días para fin de año`);

new Date("2026-10-07") (con guiones) se interpreta en hora de Londres (UTC). En Argentina eso es el 6 de octubre a las 21 h, y al mostrarla vas a ver un día menos. Preferí new Date(2026, 9, 7).

Trabajar con fechas es tan complicado que existen librerías dedicadas, como date-fns o Day.js, y una API nueva del lenguaje llamada Temporal. Averiguá qué problemas resuelven.

const ventas = [
  { producto: "Café", categoria: "bebidas", precio: 2500, cantidad: 30 },

Generá en la consola un reporte que muestre:
