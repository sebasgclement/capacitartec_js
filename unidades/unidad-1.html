¿Qué es JavaScript?

JavaScript es un lenguaje de programación que corre dentro del navegador. Ya conocés los otros dos lenguajes de la web, así que pensalo así:

LenguajeSe ocupa de…Ejemplo
HTMLla estructura y el contenidoun botón que dice “Comprar”
CSSla presentaciónque el botón sea verde y redondeado
JavaScriptel comportamientoque al hacer clic se sume el producto al carrito

Con JavaScript una página puede reaccionar a lo que hace el usuario, validar formularios, mostrar u ocultar elementos, guardar datos en el navegador y traer información de internet sin recargar.

El nombre oficial del estándar es ECMAScript. Cada año sale una versión nueva (ES2015, ES2016…). Cuando leas “ES6” se refiere a la de 2015, que trajo let, const, las funciones flecha y los template strings, entre otras cosas.

JavaScript también corre fuera del navegador gracias a Node.js. Averiguá qué es y para qué se usa (servidores, herramientas de línea de comandos, apps de escritorio).

Preparar el entorno

Para todo el curso vamos a trabajar con esta estructura mínima:

mi-proyecto/
├── index.html
├── style.css
└── script.js

El archivo JavaScript se vincula desde el <head> del HTML:

index.html

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>Mi primer script</title>
    <link rel="stylesheet" href="style.css" />
    <script src="script.js" defer></script>
  </head>
  <body>
    <h1>Hola</h1>
  </body>
</html>

script.js

console.log("¡El script está conectado!");

No te olvides del atributo defer. Le indica al navegador que ejecute el script después de leer todo el HTML. Sin él, cuando más adelante quieras modificar un elemento de la página, JavaScript todavía no lo va a encontrar.

También se puede escribir JavaScript dentro de una etiqueta <script> en el HTML o en atributos como onclick, pero en el curso vamos a usar siempre un archivo externo: queda más ordenado y es lo que se hace en proyectos reales.

En VS Code instalá la extensión Live Server: abre tu página en el navegador y la recarga sola cada vez que guardás.

La consola del navegador

La consola es la herramienta que más vas a usar. Ahí aparecen los mensajes que escribís con console.log() y, muy importante, los errores de tu código.

Para abrirla: F12 o Ctrl + Shift + J (en Mac, Cmd + Option + J) y elegí la pestaña Console. 

console.log("Hola, mundo");
console.log("Podés mostrar varios valores:", 42, true);

console.warn("Esto es una advertencia");
console.error("Esto es un error");
Hola, mundo Podés mostrar varios valores: 42 true ⚠ Esto es una advertencia ✖ Esto es un error

También podés escribir código directamente en la consola y apretar Enter. Es ideal para probar algo rápido sin tocar tus archivos.

Si tu código no hace nada, lo primero es abrir la consola. Un error en rojo te dice qué falló y en qué línea: hacé clic en el nombre del archivo que aparece a la derecha del error y te lleva directo al lugar.

Comentarios

Los comentarios son texto que JavaScript ignora. Sirven para explicar el código a otras personas (o a vos mismo dentro de un mes). 

// Comentario de una línea

/*
  Comentario de
  varias líneas
*/

console.log("Esto sí se ejecuta"); // también puede ir al final de una línea

En VS Code, Ctrl + / comenta o descomenta la línea actual.

Variables

Una variable es un nombre que guarda un valor para usarlo después. En JavaScript moderno se declaran con let o const: 

let edad = 17;        // let: el valor puede cambiar
edad = 18;            // reasignamos, sin volver a escribir let

const pais = "Argentina"; // const: el valor no se puede reasignar
pais = "Chile";           // ❌ TypeError: Assignment to constant variable.

Regla práctica: usá const por defecto y cambiá a let solo cuando sepas que el valor va a cambiar (un contador, un total que se acumula…).

Cómo nombrar variables

  • Pueden tener letras, números, _ y $, pero no pueden empezar con un número.
  • No pueden tener espacios ni ser palabras reservadas (let, if, function…).
  • Distinguen mayúsculas: nombre y Nombre son dos variables distintas.
  • Por convención se escriben en camelCase: la primera palabra en minúscula y las siguientes con mayúscula inicial. 
const nombreCompleto = "Juan Pérez";   // ✅ camelCase, descriptivo
const precioConIva = 1210;             // ✅
const x = 1210;                        // 😐 válido, pero ¿qué es x?
const 2doApellido = "Gómez";           // ❌ empieza con número

Vas a encontrar mucho código viejo que usa var. Investigá qué diferencias tiene con let (alcance de bloque y hoisting) y por qué hoy se recomienda no usarlo.

Tipos de datos

Cada valor tiene un tipo. Los que vamos a usar todo el tiempo son:

TipoQué representaEjemplos
stringtexto, entre comillas"Hola", 'Rafaela', `JS`
numbernúmeros enteros y decimales42, -3, 3.14
booleanverdadero o falsotrue, false
undefineduna variable que todavía no tiene valorlet x;
null“vacío” a propósitolet ganador = null;

Con typeof podés preguntar de qué tipo es un valor:

console.log(typeof "Hola");   // "string"
console.log(typeof 42);       // "number"
console.log(typeof 3.5);      // "number" (no hay un tipo aparte para decimales)
console.log(typeof true);     // "boolean"
console.log(typeof "42");     // "string" ← ¡ojo! está entre comillas

let sinValor;
console.log(typeof sinValor); // "undefined"

Los decimales se escriben con punto, no con coma: 3.5 es un número, 3,5 no.

typeof null devuelve "object". Es un error histórico del lenguaje que nunca se corrigió para no romper sitios existentes.

Existen otros dos tipos primitivos que casi no vamos a usar: bigint y symbol. Buscá para qué sirven.

Unir textos: concatenación y template strings

Hay dos formas de armar un texto con variables adentro:

const nombre = "Ana";
const edad = 25;

// 1. Concatenación con +
console.log("Hola, soy " + nombre + " y tengo " + edad + " años.");

// 2. Template string: comillas invertidas (backticks) y ${ }
console.log(`Hola, soy ${nombre} y tengo ${edad} años.`);

Las dos dan el mismo resultado, pero el template string es mucho más fácil de leer y de escribir. Además, dentro de ${ } podés poner cualquier expresión: 

const precio = 1000;
console.log(`Con IVA: $${precio * 1.21}`); // Con IVA: $1210

Las comillas invertidas ` en teclado latinoamericano suelen estar en Alt Gr + }, o en la tecla al lado del Enter (apretala y después la barra espaciadora).

Pedir datos: prompt y alert

Para practicar las primeras semanas vamos a usar dos funciones del navegador que muestran ventanitas: 

const nombre = prompt("¿Cómo te llamás?");
alert(`¡Bienvenido/a, ${nombre}!`);
  • prompt() muestra un cuadro para escribir y devuelve lo que escribió el usuario como string. Si apretó “Cancelar”, devuelve null.
  • alert() muestra un mensaje y espera a que el usuario apriete “Aceptar”.

En sitios reales casi no se usan porque bloquean la página y no se pueden diseñar. En la Unidad 7 los vamos a reemplazar por formularios HTML.

Convertir texto a número

Este es el error más común de las primeras clases. Probalo:

const a = prompt("Primer número");  // el usuario escribe 2
const b = prompt("Segundo número"); // el usuario escribe 3
console.log(a + b);
23

¿23? Como prompt() siempre devuelve texto, a vale "2" y b vale "3". Y el + entre dos strings los une en lugar de sumarlos. La solución es convertirlos a número antes de operar: 

const a = Number(prompt("Primer número"));
const b = Number(prompt("Segundo número"));
console.log(a + b); // 5 ✅

Funciones de conversión

Number("42");       // 42
Number("3.5");      // 3.5
Number("3,5");      // NaN  ← la coma no sirve
Number("hola");     // NaN
Number("");         // 0    ← cuidado: un campo vacío da 0

parseInt("12px");   // 12   (lee el entero del principio y corta)
parseFloat("1.5kg");// 1.5

String(42);         // "42"

NaN significa Not a Number: es el resultado de una conversión que falló. Curiosamente, typeof NaN es "number". En la próxima unidad vamos a ver cómo detectarlo para avisarle al usuario que escribió algo inválido.

El + con un string adentro siempre concatena: "5" + 1 da "51". En cambio -, * y / convierten a número: "5" - 1 da 4. No dependas de eso; convertí explícitamente con Number().

Práctica

1 · Presentación

Guardá en constantes tu nombre, tu edad y tu ciudad. Mostrá en la consola una frase usando un template string: Soy Ana, tengo 25 años y vivo en Rafaela.

2 · Detective de tipos

Antes de ejecutarlo, escribí en un papel qué va a mostrar cada línea. Después comprobalo en la consola. 

console.log(typeof 10);
console.log(typeof "10");
console.log(typeof (10 + "10"));
console.log(10 + "10");
console.log("10" * 2);
console.log(Number("diez"));

3 · Sumadora

Pedile al usuario dos números con prompt() y mostrá con alert() su suma, resta, multiplicación y división.

Pista

Si la suma te da algo como “23”, volvé a leer la sección de conversión.

4 · Conversor de temperatura

Pedí una temperatura en grados Celsius y mostrá su equivalente en Fahrenheit. Fórmula: F = C × 9 / 5 + 32.

5 · Ticket de compra (integrador)

Pedí el nombre de un producto, su precio unitario y la cantidad. Mostrá un resumen como este, incluyendo el total con IVA (21 %): 

3 × Alfajor a $850 = $2550
Total con IVA: $3085.5
Pista

Necesitás convertir precio y cantidad con Number(). Para el salto de línea dentro de un template string podés escribir el texto en dos renglones o usar \n.
